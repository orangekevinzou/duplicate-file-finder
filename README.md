# 重复文件查找工具

一个 GUI 工具，对比两个目录并找出其中的重复文件，支持多种对比策略和结果导出。

![Python](https://img.shields.io/badge/Python-3.x-blue)
![GUI](https://img.shields.io/badge/GUI-tkinter-green)
![License](https://img.shields.io/badge/license-MIT-brightgreen)

## 简介

重复文件查找工具可以扫描两个目录并识别同时出现在两个目录中的文件。提供三种对比方式，从最快的（仅文件名）到最严格的（文件名 + 大小 + MD5 哈希）。结果以树形格式显示，并可导出为文本文件。

## 功能特性

- **三种对比方式**：
  - **仅文件名** — 速度最快，按文件名匹配（不区分大小写）
  - **文件名 + 文件大小** — 速度与准确性的平衡
  - **文件名 + 文件大小 + MD5 哈希** — 最准确，计算 MD5 校验和
- **子目录支持**：可选择是否包含子目录
- **相同相对路径匹配**：可选要求文件处于相同的相对子目录下
- **树形结果展示**：重复文件以熟悉的目录树形式呈现
- **进度条**：扫描过程中提供可视化进度反馈
- **结果导出**：可将结果保存为格式化的文本报告
- **零外部依赖**：完全使用 Python 标准库（`tkinter`）

## 运行环境

- Python 3.6+
- 无需安装额外依赖（`tkinter` 随 Python 自带）

## 使用方法

直接运行脚本：

```bash
python duplicate_file_finder.py
```

1. 点击 **浏览...** 分别选择 **目录 1** 和 **目录 2**
2. 选择对比方式：
   - **文件名** — 仅按文件名匹配（最快）
   - **文件名 + 文件大小** — 文件名 + 大小匹配（推荐）
   - **文件名 + 文件大小 + MD5 哈希** — 完整 MD5 对比（最准确）
3. 根据需要勾选 **包含子目录** 和 **要求相对目录名也相同**
4. 可选勾选 **导出结果到文本文件** 并设置输出路径
5. 点击 **开始查找** 扫描重复文件

### 输出示例

